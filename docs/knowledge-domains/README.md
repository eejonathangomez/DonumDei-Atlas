## Purpose

Knowledge domains are Atlas's primary organizational unit. Each domain defines:

- **Scope** — what belongs in this domain
- **Relationships** — how this domain connects to others
- **Curation rules** — how knowledge enters and maintains provenance
- **Sources** — where domain knowledge originates

Domains are **expandable**. New domains may be added when earned; existing domains grow through documented curation.

## Curation principles

1. **Provenance required** — every entry cites source repository and artifact
2. **No duplication of constitutional docs** — link to Repository 0
3. **Experience is curated** — DDTP investigations enter Atlas through protocol, not automatic sync
4. **Relationships explicit** — cross-domain links documented in domain files
