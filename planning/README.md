# Planning branch

Branch: `atlas/planning`

This directory holds versioned proposals, ideas, enhancements, technical debt, and proposed roadmap amendments.

A file here is not execution authority. It is not READY. It does not become an approved task automatically. Promotion requires a Founder decision in `docs/decisions/FOUNDER-DECISION-REGISTER.md`. A proposal does not interrupt active work without that approval.

The approved operating record, when one exists, is `docs/CURRENT-OPERATING-ROADMAP.md`. Until its approved version leaves `NONE`, there is no approved master roadmap in this branch.

If this directory is missing, report the backlog as `UNKNOWN` and name `planning/` as the missing source. Do not reconstruct proposals from chat memory.
